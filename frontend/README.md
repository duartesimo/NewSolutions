# NewSolutions

A modern corporate website built with React, TypeScript and TailwindCSS.

NewSolutions is a fictional technology company website created as a portfolio project to demonstrate modern frontend development practices, responsive design, reusable components and full-stack integration.

The project simulates a real-world business website where companies can present their services and generate leads through a contact system.

---

## 🚀 Project Goals

The goal of this project is to build a professional website from scratch using a modern frontend stack while following industry best practices.

The project focuses on:

- Responsive design
- Reusable React components
- Clean and maintainable code
- Modern UI development
- API integration
- Full-stack architecture

## 💻 Getting Started

### Requirements

Make sure you have installed:

- Node.js
- npm

Check your versions:

```bash
node -v
npm -v
```

---

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## 🧩 Development Scripts

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
